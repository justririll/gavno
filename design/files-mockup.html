gavno-files

A file manager for GAVNO in the spirit of Nautilus. Right-click opens a terminal in any folder, and root mode is one button away.

Try it

  • Right-click the src folder. "Terminal in this folder" slides the docked terminal up from the bottom, and "Terminal in new window" opens a separate GAVNO window. You can drag it by its title bar.
  • Go to /etc through "System". Everything there is locked. Press Ctrl+Shift+R or the root button: the header turns red and you can edit.
  • Type cd .. in the docked terminal: the window follows the terminal and the other way round. Drag the handle up or down, and drag it all the way down to hide the terminal. The ⧉ button pops it out into a separate window.
  • sudo -i gives a root shell, exit returns to your user, and sudo !! repeats a command that failed with Permission denied.
  • Space opens quick look, F2 renames, Ctrl+H shows hidden files, and Ctrl+L opens the path input.

How it will work

  • The interface always runs as your own user. Root operations are handled by a small helper, gavno-files-helper, through polkit: the password is asked once and the session lasts 5 minutes.
  • The docked terminal (F4) uses the same folder as the window: cd in the terminal navigates the window, and clicking a folder runs cd in the terminal.
  • A separate terminal (Shift+F4) is launched as foot --working-directory=… and lives on its own. Which terminal to launch is set in the config.
